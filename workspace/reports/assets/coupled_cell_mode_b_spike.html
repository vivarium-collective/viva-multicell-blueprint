Mode B: a particle count drives an ODE's rate (spike)

A Smoldyn particle sim (A+B→C, confined to the cell polygon) and a tellurium ODE (S→P) run inside one cell. Each step the live C particle count sets the ODE rate constant kf0 (mode B — the particle population catalyses the metabolism). As C builds toward equilibrium the ODE accelerates, so P is concave-up; a control ODE driven by the run-mean C stays linear. The shape difference is the coupling. Both engines are real — Smoldyn through the 3.11 bridge, tellurium in-process.

Mechanism: the ODE adapter's step() ignores its inputs, so the rate is injected via the live roadrunner — ode._rr['kf0'] = base * C — the seam the CoupledCell formalisation will wrap.
